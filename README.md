# Dynamic (dynamic-xyz)

Dynamic is a wallet and authentication platform offering embedded wallets, social/email/passkey login, MPC signers, and a Backend / Admin REST API for managing users, wallets, and sessions. Provides SDKs across Web, React, React Native, Flutter, Swift, Kotlin, Node.js, Unity.

Dynamic publishes an interactive API reference at https://docs.dynamic.xyz/api-reference but no stable public OpenAPI download URL.

## APIs
- **Dynamic Backend API** - REST API for backend integrations: list users and wallets, manage policies, validate JWTs, fetch auth events, manage environments.
- **Dynamic Wallets API** - REST API to provision, sign, and manage server-controlled wallets across EVM, Solana, and other chains.
- **Dynamic Webhooks** - Webhook delivery of auth, user, wallet, and session events.
